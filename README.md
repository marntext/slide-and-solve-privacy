# Slide & Solve

Ahşap kayan blok bulmacası. Bu depo yalnızca tanıtım ve gizlilik sayfalarını
barındırır; oyunun kaynak kodu ayrı bir özel depoda.

- `index.html` — tanıtım ve destek sayfası (App Store destek adresi)
- `gizlilik.html` — gizlilik politikası, Türkçe
- `privacy.html` — gizlilik politikası, İngilizce

Sayfalar GitHub Pages ile yayımlanıyor. Kaynak dal: `main`, kök dizin.
